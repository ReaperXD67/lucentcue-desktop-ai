# LucentCue design

The desktop workspace operates as a quiet research desk: a deep evergreen navigation rail, warm paper working area, restrained green actions, and locally bundled DM Sans. This is an engineering design choice under the user's request for creative, easy-to-use execution; no final branding approval is implied.

The chat composer anchors the window. Model cost mode, current model, attachment previews, and sending state sit together. Browser and settings tools open as adjacent panels, preserving the conversation. At compact widths navigation collapses and panels occupy the content region. Dense state and empty state share the same hierarchy.

Use semantic color tokens, 4/8px spacing, 14–16px interface text, visible keyboard focus, real text labels on major actions, reduced motion, and one consistent Lucide icon family. Quiet hover feedback and a single 200ms workspace arrival are enough; text streams immediately. Destructive actions require an inline second action. Do not invent speed benchmarks, traction, partnerships, sample user conversations, or provider results.

Direction considered: a command launcher, a code-editor split, a library, a notebook, a research desk, a control console, and a browser sidebar. The research desk carries both everyday questions and source review. The reference-setting challenger reinforces readable text measure; the timetable reinforces aligned metadata; the wayfinding challenger reinforces explicit next actions. Decorative rails, rotating stamps, wall-of-posters navigation, and optical effects would obscure these tasks and are declined.
